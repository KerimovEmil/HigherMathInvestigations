# Dickson–Pillai Condition Investigations

### Key Resources in the Dedicated Repository

* **Research Manuscript:** [`paper/two_adic_proof.pdf`](https://github.com/KerimovEmil/DicksonPillai/blob/main/paper/two_adic_proof.pdf)
  * *A 2-Adic Rigidity and Automata-Theoretic Framework for the Dickson–Pillai Problem in Waring's Problem* (12 pages, AMS-LaTeX).
* **Lean 4 Formal Verification:** [`formalization/TwoAdicDefectRigidity.lean`](https://github.com/KerimovEmil/DicksonPillai/blob/main/formalization/TwoAdicDefectRigidity.lean)
  * Zero-axiom, sorry-free formal verification of 2-adic LTE valuations, discrete carry drift recurrences, dynamical repulsion laws, and automaton spectra.
* **Empirical Verification Suite:** [`scripts/two_adic_verification.py`](https://github.com/KerimovEmil/DicksonPillai/blob/main/scripts/two_adic_verification.py)
* **Supplementary Frameworks & Barriers:** [`explorations/`](https://github.com/KerimovEmil/DicksonPillai/tree/main/explorations)
  * Detailed investigations and barrier analyses for Frey curve / Szpiro modular degree bounds, Nesterenko automorphic differential algebra, Hermite–Padé hypergeometric systems, and parallel C++ streaming engines up to $k = 25{,}000{,}000$.
